### 🎬 Flagship: D&C MediaHouse

<table>
<tr>
<td>

A high-end cinematic portfolio site built as a decoupled, headless system — a Next.js frontend paired with a Sanity-powered CMS backend.

- **Adaptive HLS video streaming** via Mux + `hls.js`, so every showcase reel adjusts quality to the viewer's bandwidth in real time
- **Cinematic Mode** — an idle-triggered, distraction-free viewing state for video content
- **Headless CMS workflow** — the D&C team edits and publishes projects through Sanity Studio with zero developer involvement
- **Cloudflare (DNS-only) + Vercel Edge** — global DNS resolution paired with edge caching for fast, worldwide delivery
- **Automated CI/CD** — zero-downtime deploys via GitHub Actions

**Why it moved from Vite → Next.js:** the original Vite SPA couldn't be indexed well by search engines. Migrating to Next.js's App Router unlocked server-side rendering for real SEO, `next/font` for layout-shift-free typography, and React Server Components to trim the client-side JS bundle — all in service of a snappier, more cinematic feel.
